# 🎓 Ciallo AI 智能刷题系统 (橙白旭日/暖炭极客版)

> 极致奢华的 OKLCH 旭日/暖炭双色设计系统，集“本地智能刷题、错题本消灭战、兼容 OpenAI 全格式 AI 考点深度解析及本地零成本永久缓存”于一体的免安装本地智能刷题系统。

---

## 🌟 核心特色与功能

1. **🎨 Premium OKLCH 橙白双色主题**
   - 引入苹果高档 **Outfit / Inter** Google 字体。
   - 采用先进的 CSS **OKLCH 色彩空间**规范配制，柔和旭日橙与深邃弦月炭，支持平滑微交互，让刷题变成一种视觉享受。
   - 自定义 iOS/macOS 风格细窄滚动条，适配多端自适应网格。

2. **🤖 兼容 OpenAI 格式的 AI 深度解析**
   - 支持 any OpenAI 格式兼容的 API 端点（包括 **DeepSeek**、**Gemini**、**OpenAI**、**月之暗面**以及各类国内聚合转发 API）。
   - **零成本本地永久缓存**：一旦触发某道题 of AI 考点解析，系统自动将解析 Markdown 文本永久保存在本地数据库中。下次查阅瞬时呈现，不重复消耗任何 API Token 额度。

3. **❌ 错题消灭循环战 (错题本)**
   - 答错题目全自动计入错题本，并累加错题频次。
   - 支持**直接在错题本卡片中一键展开已存 AI 解析**的微创新。
   - **错题重做自动移除**：点击“立即攻坚消灭”进入专门的错题重做模式。只要做对，该题立刻在下一轮自动从错题本中销毁！

4. **📤 一键拖拽题库导入去重**
   - 控制面板支持直接拖拽抓取合并成功的题库 JSON（如 `merged_questions.json`）。
   - 内置强大的**标题去重合并逻辑**，全自动过滤并安全提取单项选择题，无感生成极简去重题库。

5. **⚡ 零依赖 (Zero Dependency) 纯绿运行**
   - 基于原生 Node.js 构建静态托管与 API 服务器。无需安装任何第三方 npm 依赖包，解压即用。

## 📁 目录文件结构

```text
exam_system/
├── server.js            # 原生 Node.js 静态文件 + 答题 API 聚合服务器 (运行于端口 8080)
├── package.json         # 项目描述文件，定义 npm start 极速启动命令
├── start.sh             # Mac/Linux 一键双击极速启动并自动唤起浏览器脚本
├── database.json        # 系统本地数据库 (保存题目库、作答记录、AI 解析缓存)
├── config.json          # 系统本地大模型 API 接口连接配置 (支持在前端直接修改)
└── public/              # 极光暗黑前端 SPA 单页应用资源
    ├── index.html       # 系统主结构 (侧边栏、控制面板、刷题器、错题本、设置页)
    ├── style.css        # OKLCH 发光视觉主题样式表
    └── app.js           # 前端 SPA 控制核心 (状态管理、拖拽文件、答题交互、Markdown 渲染)
```

## 🚀 极速启动与部署指南

### 1. 启动服务器

* **Mac / Linux 用户 (推荐)**：
  在解压出的文件夹中，直接**双击运行** `start.sh`，或者在终端运行：
  ```bash
  ./start.sh
  ```
  *(脚本会自动启动 Node 服务，延迟 1 秒后自动为您唤起系统默认浏览器打开答题页面！)*

* **通用启动法 (Windows 等)**：
  在项目根目录下打开命令行终端，运行：
  ```bash
  node server.js
  ```
  或者：
  ```bash
  npm start
  ```
  然后在浏览器中手动打开地址：[http://localhost:8080](http://localhost:8080)。

## 📝 深度刷题实战步骤

### 第一步：导入题库
1. 访问首页，点击或拖拽您通过爬虫抓取的题库 JSON 文件（例如 `merged_questions.json`）到控制面板的**虚线导入区域**。
2. 系统会展示极光进度条，并弹出提示告知您成功解析并灌入了多少道去重单选题。

### 第二步：配置 AI 金牌解析教练
1. 切换至 **“系统设置”**。
2. 填入您的大模型 API Base URL、您的个人 API 密钥 (API Key) 以及使用的模型名称 (Model Name)。
   * **DeepSeek 官方**：
     * API 基准地址：`https://api.deepseek.com/v1`
     * 模型名称：`deepseek-chat`
   * **Gemini 官方 (OpenAI 兼容端点)**：
     * API 基准地址：`https://generativelanguage.googleapis.com/v1beta/openai`
     * 模型名称：`gemini-1.5-flash` 或 `gemini-pro`
3. 保存配置。

### 第三步：畅快刷题与错题消灭
* 点击 **“智能刷题”**，一键选择选项，正确答案绿色发光，错误选项红色发光。
* 遇到考点模糊的题目，点击 **“🤖 深度 AI 考点解析”** 按钮，系统会调取您配好的大模型为这道题定制 Markdown 格式的深度透彻解析，并**永久保存在本地**。
* 回答错误的题会自动进入 **“错题本”**，在错题本中点击 **“开始错题重做消灭战”** 专注消灭盲区，做对即可自动摘帽子！
