# 🎓 Ciallo AI 智能刷题系统 (橙白旭日/暖炭极客版)

> 极致奢华的 OKLCH 旭日/暖炭双色设计系统，集“分科目自测、选择/简答双模块、本地智能刷题、错题本消灭战、兼容 OpenAI 全格式 AI 考点深度解析/简答打分批改及本地零成本永久缓存”于一体的免安装本地智能刷题系统。

---

## 🌟 核心特色与功能

1. **🎨 Premium OKLCH 橙白双色主题**
   - 引入苹果高档 **Outfit / Inter** Google 字体。
   - 采用先进的 CSS **OKLCH 色彩空间**规范配制，柔和旭日橙与深邃弦月炭，支持平滑微交互，让刷题变成一种视觉享受。
   - 自定义 iOS/macOS 风格细窄滚动条，适配多端自适应网格。

2. **📚 多科目状态维度筛选 (分科目功能)**
   - 侧边栏集成了高档的磨砂材质科目下拉选择框，系统能智能加载数据库中当前存在的所有科目类别（如“软件测试”、“政治与历史”）。
   - 全局控制面板统计看板、智能自测试卷库、错题消灭战场均自适应过滤至您当前选择的科目，实现专注复习。

3. **✍️ 简答题自测与 AI 对比判定**
   - 新增简答题作答交互，支持自由编辑文本回答。
   - 提交作答后系统将展开**标准参考答案**，方便直观对比。
   - 一键调用 **“AI 智能判定与对比”**，大模型将自动执行语义比对，从要点覆盖率、表述专业度两个方向分析您的回答与标准答案的差异，给出综合得分及改进建议。

4. **🤖 兼容 OpenAI 格式的 AI 解析与批改**
   - 支持 any OpenAI 格式兼容的 API 端点（包括 **DeepSeek**、**Gemini**、**OpenAI**、**月之暗面**以及各类国内聚合转发 API）。
   - **零成本本地永久缓存**：一旦触发某道题的 AI 考点解析或简答判定，系统自动将 Markdown 文本永久保存在本地数据库中（选择题缓存为 `aiExplanation`，简答题缓存为 `aiGrade`）。下次查阅瞬时呈现，不重复消耗任何 API Token 额度。

5. **❌ 错题消灭循环战 (错题本)**
   - 答错题目全自动计入错题本，简答题未掌握可手动标记纳入错题本。
   - 支持**直接在错题卡片中一键展开已存 AI 解析/批改报告**。
   - **错题重做自动移除**：进入“错题本”，点击“立即攻坚消灭”进入专门的错题重做模式。只要做对或手动标记已掌握，该题立刻在下一轮自动从错题本中销毁！

6. **📤 一键拖拽题库导入去重**
   - 控制面板支持直接拖拽抓取包含 `course`（科目）和 `type`（简答题/单选题）的题库 JSON。
   - 内置强大的**标题去重合并逻辑**，自动对题目去重并分类灌入系统，支持选择题与简答题混合导入。

7. **⚡ 零依赖 (Zero Dependency) 纯绿运行**
   - 基于原生 Node.js 构建静态托管与 API 服务器。无需安装任何第三方 npm 依赖包，解压即用。

## 📁 目录文件结构

```text
exam_system/
├── server.js            # 原生 Node.js 静态文件 + 答题与 AI 判定 API 聚合服务器 (端口 8080)
├── package.json         # 项目描述文件，定义 npm start 极速启动命令
├── start.sh             # Mac/Linux 一键双击极速启动并自动唤起浏览器脚本
├── database.json        # 系统本地数据库 (保存题目库、作答记录、AI 判定/解析缓存)
├── config.json          # 系统本地大模型 API 接口连接配置 (支持在前端直接修改提示词模板)
└── public/              # 前端单页应用 (SPA) 资源
    ├── index.html       # 系统主结构 (科目下拉框、控制面板、刷题器、错题本、设置页)
    ├── style.css        # OKLCH 发光视觉主题样式表 (新增简答题与科目选择器样式)
    └── app.js           # 前端 SPA 控制核心 (状态管理、题型自适应渲染、AI 判定分流)
```

## 🚀 极速启动与部署指南

### 1. 启动服务器

* **Mac / Linux 用户 (推荐)**：
  在解压出的文件夹中，直接**双击运行** `start.sh`，或者在终端运行：
  ```bash
  ./start.sh
  ```
  *(脚本会自动启动 Node 服务，延迟 1 秒后自动为您唤起系统默认浏览器打开答题页面！)*

* **通用启动法 (Windows 等)**：
  在项目根目录下打开命令行终端，运行：
  ```bash
  node server.js
  ```
  或者：
  ```bash
  npm start
  ```
  然后在浏览器中手动打开地址：[http://localhost:8080](http://localhost:8080)。

## 📝 深度刷题实战步骤

### 第一步：导入题库
1. 访问首页，点击或拖拽您的题库 JSON 文件（例如 `software_testing_short_answer.json`）到控制面板的**虚线导入区域**。
2. 系统会展示极光进度条，并弹出提示告知您成功导入并归类了多少道新题目。

### 第二步：配置 AI 金牌教练
1. 切换至 **“系统设置”**。
2. 填入您的大模型 API Base URL、您的个人 API 密钥 (API Key) 以及使用的模型名称 (Model Name)。
3. 在下方分别微调选择题的 **“AI 解析 Prompt 模板”** 和简答题的 **“AI 判定 Prompt 模板”**（均已提供深度内置推荐模版）。
4. 保存配置。

### 第三步：分科目刷题与错题消灭
* 在侧边栏下拉列表中选择您当前想学习的科目（例如：**软件测试**）。
* 点击 **“智能刷题”**：
  - **选择题**：一键选择选项，正确答案绿色发光，错误选项红色发光。若对考点模糊，点击“深度 AI 考点解析”查看剖析。
  - **简答题**：在输入框编写回答后点击“提交作答”查看参考答案。点击“AI 智能判定与对比”，右侧将滑出 AI 教练对您的回答与参考答案的差异比对、打分与指导。点击“掌握”或“纳入错题本”控制您的学习进度。
* 遇到盲区错题会自动进入 **“错题本”**，在错题本中点击 **“开始错题重做消灭战”** 专注复习，攻克后系统会自动将其移出。

## 🔒 个人极客隐私与安全说明

本系统为**纯本地个人使用工具**，您的所有 API 密钥、刷题历史记录、AI 解析缓存全部仅持久化保存在您本机的 `config.json` 和 `database.json` 中，**绝对不会上传至任何第三方大模型云端之外的服务器**，安全且快速。
